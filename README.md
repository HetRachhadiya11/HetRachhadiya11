### Inspect the engineering

**Agent Anvil 0.2.1**, verified on 24 November 2026: **18 passing tests**, **80% package-only statement/branch coverage**, **5 passing smoke scenarios**, and **100 validated scenario definitions across five suites**. CI checks Python 3.10, 3.11 and 3.12.

The local demonstration shows a plausible final answer passing a basic response check while an invalid action fails the trace and state checks. It runs without an API key.

[Try the demonstration](https://github.com/HetRachhadiya11/agent-anvil/blob/main/docs/DEMO.md) · [Verification record](https://github.com/HetRachhadiya11/agent-anvil/blob/main/VERIFICATION.md) · [Live CI](https://github.com/HetRachhadiya11/agent-anvil/actions/workflows/test.yml) · [Architecture](https://github.com/HetRachhadiya11/agent-anvil/blob/main/docs/ARCHITECTURE.md)

These results verify software behaviour using controlled fixtures. Evaluation with real model providers is a separate research activity.
